# HSC3D

HSC3D (version 0.2.0 in the paper) quantifies habitat structural complexity from photogrammetry point clouds. Point clouds keep more of the structure organisms actually experience than 2.5D rasters such as DEMs, DSMs, and DTMs. The package includes plotting functions so the calculations can be checked visually.

The published case study compares structural complexity created by two intertidal ecosystem engineers, mussels and oysters.

## Installation

```bash
pip install HSC3D
```

## Quick start

Volume metrics are off by default so the object loads faster. `compute_all()` and `plot_all()` run the implemented metrics and their figures.

```python
from HSC3D import HSC3D

hsc3d = HSC3D("path/to/your/pointcloud.ply")
hsc3d.compute_all()
hsc3d.plot_all()
```

Pass `volume=True` to include convex-hull and alpha-shape volumes. Either volume metric can be turned off on its own:

```python
hsc3d = HSC3D(
    "path/to/your/pointcloud.ply",
    volume=True,
    compute_alpha_shape=False,
)
```
