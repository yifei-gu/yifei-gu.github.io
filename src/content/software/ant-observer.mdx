# Ant-observer

Ant-observer is a computer vision system designed for automatic acquisition and analysis of ant species abundance and interactions in the field.

## Features

- Automatic ant detection and tracking
- Species identification using deep learning
- Interaction analysis between individuals
- Field-deployable camera trap integration
- Real-time counting and classification

## Installation

```bash
pip install ant-observer
```

## Quick Start

```python
from ant_observer import Detector

# Initialize detector
detector = Detector(model='best.pt')

# Process video
results = detector.process_video('field footage.mp4')
print(results)
```

## Use Cases

- Biodiversity monitoring in tropical forests
- Invasive species detection
- Community ecology studies
- Long-term ecological research
