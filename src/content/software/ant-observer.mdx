# Ant-observer

Ant-observer pairs consumer-grade cameras with a desktop program for bait experiments. Manual photos and direct counts miss how abundance and interactions change through a trial. The software has a graphical interface for collecting video and for analysing it afterwards.

From each video it can:

1. Count species abundance in a frame
2. Calculate species speed
3. Detect interactions between ants
4. Count subcastes of a species on the bait

The paper reports ten in situ trials in Hong Kong, each 1 to 1.5 hours, and the variables recovered from them: resource discovery time, nestmate recruitment rate, and interspecific interactions. A handbook and an example dataset are linked from the repository README. This is not a `pip` package: download the project zip and start `Ant-Observer.exe`.
