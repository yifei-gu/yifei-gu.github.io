# CNN-SS-mussel

This repository is the code for a comparison of convolutional networks that segment intertidal mussel beds. It is a research codebase, not a packaged library: there is no `cnn-ss-mussel` install and no single `Segmenter` class to import.

The README sets up the stack as follows:

- Conda environment with Python 3.8 (3.7 if a dependency fails)
- PaddlePaddle, with a GPU build when CUDA is available and a CPU build otherwise
- PaddleX 2.1.0 for the segmentation API
- EISeg (PaddleSeg) for interactive image labels

Follow `README.md` in the repository for the exact install commands, dataset layout, and training entry points. Model names and scores belong in the paper; they are not restated here because a machine-readable abstract was not available from OpenAlex, Crossref, or Semantic Scholar when this page was written.
