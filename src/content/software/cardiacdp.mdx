# CardiacDP

CardiacDP reads cardiac recordings and estimates average heart rate per analysis interval. Heartbeats are found with the autocorrelation function. A genetic algorithm searches that autocorrelation so noise is dropped and more of the record is used. A tracking index looks back at earlier time points when the waveform is irregular.

The journal article compared the algorithm with manual rates for 33 marine invertebrates from nine species of gastropods, bivalves, and crustaceans. Mean data utilization was above 90%, and the mean absolute percentage error was 3%. The method does not assume a fixed waveform, so the same code can be tried on other periodic series such as valvometry, acoustics, or movement.

An earlier preprint of the algorithm is on SSRN (5153081). The version to cite is the 2026 paper in *Limnology and Oceanography: Methods*.

## Installation

```r
install.packages("CardiacDP")

# or the GitHub sources
devtools::install_github("Vicellken/CardiacDP")
```

## Quick start

`computeHR()` returns average heart rate. If you pass a zip of raw files, `collatedata()` runs first. Nothing is written unless `save_outputs` is TRUE.

```r
library(CardiacDP)

output <- computeHR(
  file_path = "collated_heart_rate.csv",
  save_outputs = TRUE,
  verbose = TRUE
)
```
