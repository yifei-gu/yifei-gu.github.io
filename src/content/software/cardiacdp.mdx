# CardiacDP

Automated heart rate data processing using advanced signal processing and optimization algorithms.

## Features

- Autocorrelation-based peak detection
- Genetic algorithm optimization
- Noise robust processing
- Batch processing support
- Export to common formats

## Installation

```bash
pip install cardiacdp
```

## Quick Start

```python
from cardiacdp import analyze

# Analyze heart rate data
results = analyze('ecg_data.csv')
print(f"Heart rate: {results.bpm} BPM")
```

## Algorithm

The tool combines:
1. Autocorrelation function (ACF) for periodicity detection
2. Genetic algorithm for parameter optimization
3. Tracking index for quality assessment
