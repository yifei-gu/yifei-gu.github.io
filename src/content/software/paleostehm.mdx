# PaleoSTeHM

A modern, scalable framework for Spatio-Temporal Hierarchical Modeling of paleo-environmental data.

## Features

- Hierarchical Bayesian modeling
- Spatio-temporal interpolation
- Large-scale data support
- Parallel processing
- Integration with common paleodata formats

## Installation

```bash
pip install palalostehm
```

## Quick Start

```python
from palalostehm import PaleoModel

# Initialize model
model = PaleoModel(training_data)

# Fit model
results = model.fit()

# Reconstruct
reconstruction = model.reconstruct(new_locations)
```
