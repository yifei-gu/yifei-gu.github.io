# PaleoSTeHM

PaleoSTeHM is a set of Jupyter notebooks for spatio-temporal hierarchical models of paleo-environmental data. The API sits on [Pyro](https://pyro.ai/) and PyTorch, so models can use autodiff and GPUs. Tutorials and the project site are at [paleostehm.org](https://paleostehm.org). There is no `palalostehm` package and no `PaleoModel.fit()` entry point; start from the notebooks in the repository.

I contributed fixes on [this fork](https://github.com/Vicellken/PaleoSTeHM). The framework paper below is the project citation. I am not an author on it.
