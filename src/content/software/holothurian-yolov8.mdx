# holothurian-YOLOv8

This repository is the code for a YOLOv8 pipeline that detects sea cucumbers in turbid subtidal imagery. Photos were taken with a consumer waterproof camera (GoPro Hero9 Black). Photometric augmentation is used so a small training set still generalizes to unseen sites. Eigen-CAM shows the regions the model uses on images it was not trained on.

On the reported test, mean average precision was 94.1%.

## Setup

The project is not a pip package. The README uses a conda environment and Ultralytics:

```bash
conda create -n yolo python=3.11 -y
conda activate yolo
pip install ultralytics
```

Install a PyTorch build that matches the machine, then use the `EigenCAM` and `utils` folders in the repository for explanations and file handling.
