# BTFr

BTFr fits Bayesian transfer functions in R. The public package is installed from the upstream repository. My [fork](https://github.com/Vicellken/BTFr) is where contributed fixes live. The fork README documents optional multi-core MCMC and cross-validation; set `parallel = FALSE` to keep the original single-core behaviour.

This package is not one of the papers on my Google Scholar profile.

## Requirements

Install [JAGS](https://sourceforge.net/projects/mcmc-jags/) before the R package.

## Installation

```r
devtools::install_github("ncahill89/BTFr")
library(BTFr)
```

## Quick start

```r
modern_mod <- run_modern(
  modern_elevation = NJ_modern_elevation,
  modern_species = NJ_modern_species,
  n_cores = 4
)
```

The upstream vignette is linked from the repository README.
