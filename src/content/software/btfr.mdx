# BTFr (Bayesian Transfer Function)

A package for reconstructing past environmental conditions using Bayesian transfer functions.

## Features

- Modern Bayesian implementation
- Transfer function for paleo-proxies
- Uncertainty quantification
- Cross-validation tools
- Visualization suite

## Installation

```r
# Install from GitHub
devtools::install_github("your-username/BTFr")
```

## Quick Start

```r
library(BTFr)

# Run transfer function
results <- btfr(reconstruction = proxy_data, 
                training = training_set)
                
# Plot results
plot(results)
```
