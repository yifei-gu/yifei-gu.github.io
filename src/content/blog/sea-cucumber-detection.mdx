# Detecting Sea Cucumbers with Explainable AI

Monitoring marine organisms in turbid subtidal habitats is incredibly challenging. Poor visibility, complex backgrounds, and variable lighting make traditional survey methods unreliable — and manual analysis of underwater imagery painstakingly slow.

## The Challenge

Sea cucumbers (holothurians) play vital ecological roles in marine ecosystems, yet monitoring their populations in turbid waters has remained difficult. We set out to build an automated detection system that could:

1. **Work in low-visibility conditions** — turbid water with poor contrast
2. **Provide explainable results** — not just a black box, but insights into _what_ the model sees
3. **Be practical** for field researchers to use

## Our Approach

We developed a custom pipeline combining YOLOv8 object detection with explainability tools to provide transparent, interpretable results. The system not only detects sea cucumbers but also highlights the features it uses for detection.

## Key Results

- High detection accuracy even in turbid conditions
- Explainable AI visualizations showing model reasoning
- Practical tool ready for deployment in monitoring programs
