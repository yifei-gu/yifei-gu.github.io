# HSC3D: A Python Package for 3D Habitat Analysis

Habitat structural complexity helps explain ecological patterns, but many existing metrics give a thin or biased picture of that structure. Photogrammetry now makes 3D reconstructions practical. Point clouds represent the habitat more faithfully than 2.5D rasters (DEM, DSM, DTM), and HSC3D is the Python package we wrote so ecologists can quantify those clouds with defined metrics and see the steps in the plots.

## What it does

HSC3D 0.2.0 loads a point cloud and computes the package metrics, with optional convex-hull and alpha-shape volumes. The paper demonstrates it on mussel and oyster beds, two intertidal ecosystem engineers that build different structures.

```bash
pip install HSC3D
```

```python
from HSC3D import HSC3D

hsc3d = HSC3D("path/to/your/pointcloud.ply")
hsc3d.compute_all()
hsc3d.plot_all()
```

Code and a sample notebook are on [GitHub](https://github.com/Vicellken/HSC3D).
