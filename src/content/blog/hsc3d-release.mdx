# HSC3D: A Python Package for 3D Habitat Analysis

Understanding habitat structural complexity is fundamental to ecology — complex habitats support greater biodiversity. But quantifying this complexity in three dimensions has always been challenging.

## The Problem

Traditional methods for measuring habitat complexity rely on 2D proxies: chain-and-tape methods, rugosity indices from transects, or simple height measurements. These approaches lose critical information about the three-dimensional structure that organisms actually experience.

## Our Solution

**HSC3D** is an open-source Python package that computes a suite of 3D structural complexity metrics from point cloud data. Whether your data comes from photogrammetry, LiDAR, or structured-light scanning, HSC3D can process it.

### Key Features

- 📊 Multiple complexity indices (fractal dimension, surface area ratio, vector dispersion, etc.)
- 🎯 Works with any point cloud format
- ⚡ Optimized for large datasets
- 📖 Comprehensive documentation and tutorials

## Getting Started

```bash
pip install hsc3d
```

The package is available on PyPI and GitHub. Check out the [documentation](https://github.com) for detailed tutorials and examples.
